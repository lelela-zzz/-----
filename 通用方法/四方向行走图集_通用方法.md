# 四方向行走图集 · 通用方法（唯一有效版本）

> 适用：已有角色像素图（正/侧/背三视图），要产出 **4 列 × 4 行** 的四方向行走图集，
> 且**不允许重绘角色、不允许改变任何部件的原始尺寸**。
>
> 本文是唯一版本，取代此前所有方案。「代码重绘」「单腿摆动」「髋膝两骨骼剪切」
> 三版实现归档在 `_废弃_重绘路线/`、`_v1_单腿摆动/`、`_v3_骨骼剪切/`，仅作对照。

---

## 0. 三条不可违反的不变量

先记住这三条，后面所有参数都从它们推出来：

| # | 不变量 | 判据 |
|---|---|---|
| **I1** | 每个部件都是原图素材的**整数平移**，尺寸八帧恒等 | 单只靴子宽/高/面积 = 原图，逐帧相等 |
| **I2** | 任何一帧的像素都必须落在「所有拷贝的并集」内 | 并集外新增像素 = 0 |
| **I3** | 鞋底最低行 = 原图鞋底行，抬脚只上移不下移 | 最低行恒为基线行 |

**最容易犯的错：把「并集变大」误判成「靴子变大」。**
拷贝本身从不变形（I1 恒成立），但两条腿是同一份素材的两份拷贝，并集宽度 = `W + 2S`。
`S` 取大了，并集就像一只被拉宽的大鞋——这是**步幅**的问题，不是靴子的问题。
修的时候要去调步幅，不要去调靴子。

## 1. 前置测量（决定动作模型与步幅上限）

### 1.1 两级坐标系（必查，坑在这里）

原图视图贴进格子会加一个 `PAD_Y` 偏移，**视图坐标 ≠ 格子坐标**。
本例 `PAD_Y = 2`，两者差 2 行：

| 量 | 视图坐标 | 格子坐标 |
|---|---|---|
| 裙摆最低行 `HEM_LAST` | 99 | 101（有起伏时 102） |
| 可见腿首行 | **100** | **102** |
| 鞋底 / 地面基线 `SOLE_ROW` | **118** | **120** |

> 把视图坐标当格子坐标用，会让抬脚时的腿部像素盖到裙摆上（`ty < LEG_TOP` 判定失效 2 行），
> 表现为"裙摆下摆被吃掉一条"。**裁剪线必须用格子坐标 `PAD_Y + LEG_TOP_VIEW`。**

### 1.2 本例实测（56 × 124 单格）

| 量 | 值 |
|---|---|
| 裙摆最低行 | 99（视图） |
| 可见腿区间 | 100 – 118（视图），共 **19 行** |
| 分成两段 | 100–102 深灰裤脚（3 行）+ 103–118 靴子（16 行） |
| 单腿块包围盒 | 朝左 **23 × 19 / 336 px**；朝右 **22 × 19 / 337 px** |
| 靴子本体包围盒 | 朝左 **23 × 16 / 291 px**；朝右 **22 × 16 / 290 px** |
| 靴筒上沿 | 素材第 3 行（= 格子第 105 行） |
| 地面基线 | 格子第 120 行 |

**判定规则**：在可见腿区间内看不到髋、膝、踝三者中的任何一个，就必须放弃骨骼链，
改用**整体刚性平移**。

本例依据：围裙下沿到膝，髋/膝/踝全在围裙之内。此前按"髋 98 / 膝 106 / 踝 112"
做逐行折线位移，结果是靴筒被剪斜、鞋头被拉长——不是参数问题，是模型选错。

### 1.3 靴子本体的边界怎么定

不要用"行号猜"，用**颜色**定：从第一处棕色像素（`R - B > 22`）起到素材底部就是靴子本体，
上面就是深灰裤脚。这样换角色、换配色都不用改常量。

## 2. 尺寸预算表：步幅是唯一能调的旋钮

并集宽度是几何恒等式：

```
并集宽 W_union = W_leg + 2S        （W_leg = 单腿块宽，S = 步幅）
```

本例 `W_leg = 23`，实测：

| 步幅 S | 两脚距 | 并集宽 | 并集面积 | 面积倍数 | 观感 |
|---|---|---|---|---|---|
| 0 | 0 | 23 | 359 | 1.07× | 只有明暗在变，读不出迈步 |
| 1 | 2 | 25 | 373 | 1.11× | 几乎看不出两只 |
| 2 | 4 | 27 | 403 | 1.20× | 后跟/鞋尖各露 2px，勉强 |
| **3** | **6** | **29** | **437** | **1.30×** | **后跟、鞋尖各露 3px，可读且不显大 ← 采用** |
| 4 | 8 | 31 | 468 | 1.39× | 鞋开始显宽 |
| 5 | 10 | 33 | 502 | 1.49× | 明显两只，但已像大鞋 |
| 6 | 12 | 35 | 536 | 1.60× | 已经像大鞋 |
| 8 | 16 | 39 | 597 | 1.78× | **读成一只超大的鞋（被否决的那版）** |

**选参数的规则：并集面积倍数 ≤ 1.30×。**
超过 1.3 就会被读成"鞋子变大了"，低于 1.1 就读成"只有一只脚"。
1.3 同时是「可辨」和「不超标」的分界，正好可用。

为什么 3px 是这个尺寸下的物理上限：**原图侧视本身只给出一个 23px 宽的靴子轮廓**，
两只脚在这个尺度上最多各露 3px（后脚跟 3px、前鞋尖 3px）。
这就是像素画在这个尺寸上的常规做法，也是"不新增像素"能给出的最大步幅。

## 3. 四相位表（每条腿 4 个相位，两腿错开 2 帧）

`S` = 步幅，`L` = 摆动离地高度，`P` = 蹬地离地高度。

| 相位 | 含义 | (Δx, Δy) | 接地状态 |
|---|---|---|---|
| P0 | 迈出并落地 | `(+S, 0)` | 鞋底贴基线 |
| P1 | 垂直支撑，脚在髋下 | `(0, 0)` | 鞋底贴基线 |
| P2 | 后伸蹬地、脚跟抬起 | `(-S, -P)` | 离地 `P` px |
| P3 | 屈膝前摆、悬停落点上方 | `(+S, -L)` | 离地 `L` px |

```
近侧腿（原色）  帧序 = [P0, P1, P2, P3]
远侧腿（压暗）  帧序 = [P2, P3, P0, P1]
```

本例取值：`S = 3`、`L = 3`、`P = 2`。

四条硬约束：

1. **支撑脚匀速后移**：P0→P1→P2 每帧位移量相等（都是 `S`），否则出现滑步。
2. **每帧恰好一只脚在基线上**：`P0`/`P1` 由近腿接地，`P2`/`P3` 由远腿接地。
   不得两只同时离地，也不得两只同时落地。
3. **P3 的横向位置 = P0 的横向位置**：摆动帧悬停于落点正上方，只差垂直 `L` px 下落。
   这样帧 4 → 帧 1 只有垂直落差、没有横向跳变，循环必然闭合。
4. **`P ≥ 1`**：蹬地脚必须离地，否则两只鞋底同行，并集会读成一只加宽的鞋。

> 4 帧循环里每条腿只摆动 1 帧，一次要跨 `2S`。这是 4 列布局的固有代价，
> 要更平滑只能加到 6 / 8 列，不能靠调参数解决。

## 4. 前后层次（并集分不开时靠明度）

1. **远腿整体 ×0.62**：在**原色上直接乘系数**。
   绝不要"在原调色板里找同亮度色"——那张调色板里有银白头发，亮度匹配会挑到灰色，
   贴到靴子上就是一道白线（已踩过两次）。
2. **远腿被近腿压住的那 1px 边缘再 ×0.72**：这是遮挡缝，让前后关系有像素级依据。
3. **绘制顺序**：远腿 → 近腿 → 缝线。缝线只压在**远腿**上，不能压近腿
   （压在近腿上会读成"腿断了"）。
4. 不要给远腿套整圈暗轮廓：试过最暗色和中调两种，都会让后面"吊着一只黑色小脚"。

## 5. 裁切与身体起伏

- 平移后**一律裁掉 `y < PAD_Y + LEG_TOP_VIEW` 的部分**（本例格子第 102 行）：
  不许画进裙摆，顶部缺口由衣摆遮挡，不会露馅。
- 抬脚时顶部被裁，看起来靴筒变短——这是正确的遮挡，不是尺寸变化；
  **靴子的完整高度始终等于原图**（裁掉的是被衣摆挡住的部分）。
- 身体起伏 ≤ 1px，且必须整块平移。它会带动 `HEM_LAST` 在 101/102 之间移动，
  但**腿部区间恒定取 `102 .. 120`**，不要跟着起伏改。
- 正/背面是另一套动作（裙摆以下切成左右两半，一半上抬 3px + 内收 1px，压暗 0.88），
  与侧视不共用任何参数，只共用格子尺寸与轴线对齐。

## 6. 验收清单（脚本内置，逐项打印）

| # | 检查项 | 本例结果 |
|---|---|---|
| 1 | 单只靴子宽/高/面积 = 原图，八帧恒等 | 23×19 / 336px 全等 |
| 2 | 并集外新增像素 = 0（I2） | 0 |
| 3 | 鞋底最低行 = 基线（I3） | 120 恒等 |
| 4 | 并集面积倍数 ≤ 1.30× | 1.19× / 1.30× |
| 5 | `alpha ∈ {0,255}`，无半透明 | 半透明 0 |
| 6 | 无任何部位触格边 | 0 帧 |
| 7 | 每帧恰好一只脚在基线 | OK |
| 8 | 支撑脚每帧位移相等（无滑步） | 3 / 3 / 3 |
| 9 | 裙摆及以上四帧一致（仅允许 1px 起伏） | OK |
| 10 | 未改动的两排逐像素不变 | 第 1/4 排与上一版全等 |
| 11 | 帧间差异量均匀（无停顿帧） | 3064 / 3064 / 3064 / 3063 |

第 1、2 项是"零新增像素"的可证判据：对每帧重新算出两份拷贝的掩膜并集，
断言 `实际腿部像素 ⊆ 并集` 且 `并集 ⊆ 实际腿部像素`。两者都成立，
就证明了这一帧里不存在任何一个是"新画"的像素。

第 11 项很关键：四段差异量接近，说明循环匀速、没有"走一下停一下"。
差异量为 0 说明该帧没动，会读成卡顿。

## 7. 三件做不了的事（写清楚，避免反复返工）

1. **摆臂**：原图的近侧手臂直接画在背心上，身下没有独立图层。
   手臂一移动就露洞，补洞等于重绘背心，与"不重绘"冲突。
   试过矩形位移补色、颜色掩膜 + 纵向补色、只摆小臂三版，均有拖影或双轮廓。
   → 侧视手臂静止。要摆臂必须允许重绘手臂下方那一小片背心。
2. **脚跟抬起（踝关节旋转）**：只允许整数复制时无法旋转像素。
   等价可读信号是"整只脚离地 2px"，但读不出"脚跟高、脚尖低"。
3. **膝弯曲**：膝关节落在衣摆之内、画面里不存在，画出来就是错的。

## 8. 换角色复用流程

1. **抠图**：从画面四边界做洪水填充去背景，不能全图按近白阈值抠
   （否则银发、白衬衫会被打穿）。
2. **切视图**：按列投影找 `>10px` 的空隙分段；确认每段朝向，
   **尽量让原图段序直接等于目标行序**，避免镜像——镜像会让配件换边。
3. **量第 1.2 节的数**，分别记视图坐标和格子坐标，写出
   `HEM_LAST / LEG_TOP / SOLE_ROW / W_leg`（两套坐标系都要）。
4. **判模型**：区间内是否可见关节？不可见 → 刚性平移；可见 → 才考虑分段。
5. **定步幅**：查第 2 节预算表，取 `并集面积倍数 ≤ 1.30×` 的最大 `S`。
6. **套相位表**，`L = 3`、`P = 2`；远腿 ×0.62、缝线 ×0.72。
7. **跑验收 11 项**，重点看第 1、2、4、11 项。
