## 一、实例实测数据（可复现基线）

这一节是全文的地基。所有后续参数均由实测反推，不是经验估值。

| 项目 | 源 2D 立绘 | 目标像素图 |
|---|---|---|
| 画布尺寸 | 1024 × 1536 | **240 × 120**（4 帧横排） |
| 单帧尺寸 | — | 44 / 39 / 44 / 47 px 宽 × 120 px 高 |
| 头顶—脚底 | 27 – 1535（高 1508） | 0 – 119（**上下均触边，说明画布按统一基线裁切**） |
| 头身比 | 约 **6.2** 头身 | 约 **3.4** 头身 |
| 头部占全高比例 | ≈ 16% | ≈ 29%（约 35 px） |
| 唯一色数量 | 数万级（连续色阶） | 原作品估计 **12–20 色** |

### 单帧垂直分段（据逐行剪影宽度反推，f0 正面）

```
y  0– 34  头部（含发型外扩）   35 px  29%   ← 全帧最宽处在 y≈24（发缘）
y 34– 40  颈部                  6 px   5%   ← 剪影最窄处 y=36（宽 24）
y 40– 56  肩胸 / 马甲上段       16 px  13%
y 56– 78  腰腹 / 皮带 / 围裙上   22 px  18%   ← 叉腰姿势使 y=72–78 达满宽 44
y 78–100  围裙下摆（破边）      22 px  18%
y100–119  裤 + 长靴             20 px  17%   ← 靴筒被刻意加高、占比放大
```

### 剪影宽度差（多视图一致性的量化证据）

| 视图 | 宽 | 相对正面 | 原因 |
|---|---|---|---|
| 正面 | 44 | 100% | 叉腰，手臂外张 |
| 侧面 | 39 | 89% | 前后进深小于左右肩宽 |
| 3/4 侧 | 44 | 100% | 介于两者之间 |
| 背面 | 47 | 107% | 头发后部外扩 + 围裙绑带 |

> 这一组数字本身就是约束：**侧面必须明显窄于正面，背面必须略宽于正面**。若你的像素图四个视图宽度接近，说明体块理解错了。

### ⚠️ 关于参考图的致命问题

实测该像素参考图为 **JPEG 有损压缩**：抠除背景后仍有 **9979 个唯一色**。而正常 44×120 像素角色应在 12–20 色内。

后果：**直接吸色会吸到压缩伪影产生的"脏色"**（实测 K-means 聚类出的主色是 `#54493E`、`#CBBEAE` 这类灰浊色，与作者真实色板不符）。

**对策：**
1. 参考图只用于学**结构与取舍**，绝不用于吸色。
2. 色板必须按材质**重建**（见第五节）。
3. 自己产出像素作品时，**只用 PNG（无 Alpha 混合 / 最近邻缩放）导出**，禁止 JPEG。

## 二、五条核心原则

### 1. 剪影优先（Silhouette First）
像素角色的识别度 90% 来自外轮廓。判定标准：把成品填成纯黑，仍能认出是谁。
本角色纯黑剪影必须保留三件事：**蓬松外扩的银白发**、**A 字展开的围裙**、**高筒靴**。

### 2. 比例重映射，而非等比缩小
等比缩小 1024→44 会把角色压成一根面条。正确做法是**分段非线性重映射**：
- 头部：几乎不压缩，相对放大 **≈ 1.8 倍**（16% → 29%）
- 躯干：轻度压缩
- 腿部：中度压缩，但**靴筒单独加高**
- 手脚：相对放大（手要能看清姿势，脚要能踩住地面）

### 3. 材质级色阶，不是全图统一色板
连续立绘靠渐变表现体积，像素靠"每个材质 2–4 阶硬边色块"。
**不同材质不共用色阶**：头发的暗部是冷灰，马甲的暗部是暖褐，二者不能混用。

### 4. 结构线代替细节线
连续立绘用大量细线描述褶皱。像素画里，**一条 1px 线就能砍掉半个细节层**。
只保留"区分部件归属"的线（马甲与衬衫交界、围裙与腰带交界、靴筒翻边），褶皱一律舍弃或以 1–2 px 色块暗示。

### 5. 多视图共用一套网格
四个视图必须共用：同一画布高度（120）、同一脚底基线（y=119）、同一头高（35 px）、同一色板（≤20 色）。
否则动画拼接时会"头忽大忽小、脚忽上忽下"。

## 三、九步流水线

### Step 0 · 素材预处理
- 抠净背景（棋盘格 / 白底），保留发丝外缘的完整轮廓。
- 确认立绘为**正交正视角**；若有透视，先做轻度正视化校正。
- 在立绘上标出四条水平参考线：**头顶、下巴、胯线、脚底**。

> 本角色实测（1024×1536 画布）：头顶 y≈45，下巴 y≈205，脚底 y≈1030。
> 头高 ≈160，身高 ≈985 → 6.2 头身。

### Step 1 · 定画布预算
先定尺寸，再画内容。角色像素尺寸的经验区间：

| 用途 | 单帧建议尺寸 | 头身比 | 备注 |
|---|---|---|---|
| 地图/棋盘小单位 | 24×32 ~ 32×32 | 2.5–3 | 只能保留 S 级特征 |
| 步行/战斗通用（本例） | **44×64 ~ 48×80** | 3–3.5 | 可保留 1–2 个 A 级特征 |
| 立绘式展示 / 对话头像 | 64×96 ~ 96×128 | 3.5–4.5 | 可上 4 阶色 |

本例为 44×120（偏高瘦），适合纵向展示型素材；若要接入常规 RPG 引擎，建议改为 **44×64**，把 120 高度里的 40 px 空耗裁掉。

### Step 2 · 比例重映射
按第一节的分段表，把立绘的目标点映射到像素画布的整数行上：

```
源 6.2 头身 → 目标 3.4 头身
头高  = 120 / 3.4 ≈ 35 px
下巴  = y 35
肩线  = y 46
腰线  = y 62
围裙下摆 = y 100
脚底  = y 119
```
**每一段都必须是整数像素**，不允许"大约 34.5"。

### Step 3 · 剪影草图（只用 1 色）
用单一中间色（如 `#7A6A58`）铺满整个剪影，**不看任何细节**。
此时唯一任务：让外轮廓成立。
- 头发：先画"团块"，不画发丝。本例发量外扩，最宽处比肩略窄。
- 围裙：A 字梯形，下摆必须有**破边锯齿**（3–4 px 起伏）。
- 靴：靴筒占小腿 2/3，靴口外翻 1 px。
- 姿势：立绘是"左臂叉腰、右手垂放"。像素版要**保留这个非对称**——它是最强的姿态识别点。叉腰使手臂外张，剪影在该行达到满宽。

### Step 4 · 色板重建（关键步骤）
**不要吸色。**按材质建卡，每材质给亮 / 中 / 暗三阶，暗部保持同色相、降明度并略偏冷。

见第五节色板表。全角色总色数控制在 **14–18 色**。

### Step 5 · 部件分块填色
按"材质区域"整块填充中调色，暂不加明暗：
```
头发  → 皮肤（脸 + 双手）→ 衬衫 → 马甲 → 皮带 → 围裙 → 裤 → 靴
```
顺序原则：**从内到外、从后到前**。被遮挡部分不画。

### Step 6 · 明暗铺设
- **固定单一光源：左上方**（本例与立绘一致，脸右侧有阴影）。
- 每个材质只加**一阶暗部**（右下方向 1–2 px 宽的色块）+ **可选一阶高光**（仅金属、皮革、头发）。
- 禁用渐变色、禁用抖动（dithering）——本例是纯硬边色块风格。
- 关键位置：下巴投影（颈部 2 px 暗）、马甲下沿压围裙（1 px 暗）、靴筒受围裙遮挡处（1 px 暗）。

### Step 7 · 特征锚点（决定"像不像"）
按识别度分级，**画布越小，能保留的层级越低**：

| 级别 | 特征 | 44 px 宽是否保留 | 像素表现手法 |
|---|---|---|---|
| **S** | 银白蓬松碎发 | 必留 | 5–7 个尖角块，外层亮色、内层暗色勾出分离 |
| **S** | 棕色马甲（V 领） | 必留 | 深色块 + 1 px 亮边表示翻领 |
| **S** | 米白围裙（A 字破边） | 必留 | 大面积中间调 + 底部 1 px 锯齿暗边 |
| **S** | 棕色高筒靴 | 必留 | 靴筒 8–10 px，靴口 1 px 翻边亮线 |
| **A** | 腰间钥匙串 + 钱袋 | 保留 1 处 | 3–5 px 的深色小簇 + 1 px 金属高光；**只画轮廓，不画钥匙齿形** |
| **A** | 衬衫挽袖至肘 | 保留 | 上臂白 → 前臂肤色的分界必须清晰 |
| **A** | 棕色皮带 + 扣 | 保留 | 1 px 深色横带 + 2 px 亮色扣 |
| **B** | 马甲纽扣数量（4 颗） | 最多保留 3 px 暗示 | 2–3 个 1px 点 |
| **B** | 围裙缝线、布料褶皱 | 舍弃 | 以 1 px 暗块暗示 |
| **C** | 发丝根数走向、靴面缝线、五官细节 | 舍弃 | 眼睛 2×2 px，嘴 1–2 px，鼻子省略 |

> 判断标准很简单：**该特征小于 2×2 像素时，它已经不存在了**——不要试图在 1 像素里表达钥匙齿。

### Step 8 · 描边与网格纪律
- **外轮廓统一描边**：用 `#2A1F1A`（偏暖深褐），**不要纯黑**。纯黑会让角色看起来像贴纸。
- **内部结构线**用比填充暗 1–2 阶的同色相，不用描边色。
- **禁止抗锯齿**：所有边缘必须在像素格上，无半透明过渡像素。
- **斜线阶梯均匀**：45° 用 1-1-1 阶梯，缓斜用 2-1-2 或 2-2-1，同一条线内不允许阶梯长度突变。
- 导出必须 **最近邻（Nearest Neighbor）**，且为 PNG。

### Step 9 · 多视图扩展与一致性校验
以正面为母版，横向复用骨架：
1. **先复制头部块**，只改脸朝向（侧面时面部收进 3–4 px，头发后部外扩 3 px）。
2. **保持肩线、腰线、脚底三线绝对对齐**——这是动画不抖的前提。
3. 侧面：躯干进深压缩，宽度应是正面的 **≈ 85–90%**（本例实测 89%）。
4. 背面：画马甲后片、围裙绑带结、头发后部完整团块，宽度应略大于正面（本例 107%）。
5. 四视图并排对比，眯眼检查：**头高是否一致、靴筒高度是否一致、围裙下摆是否在同一水平线**。

## 四、常见错误与成因

| 错误现象 | 根本原因 | 修正 |
|---|---|---|
| 成品糊成一团 | 直接缩小原图 / 自动像素化滤镜 | 手工按 Step 3–7 重画，缩图只能当参考底稿 |
| 颜色发灰发脏 | 从 JPEG 素材吸色（本例实测 9979 色污染） | 按材质重建色板，总色数 ≤ 20 |
| 角色像贴纸 | 用纯黑描边 + 无内部结构线 | 描边改暖深褐，内部用同色相暗阶 |
| 边缘有毛刺 | 缩放算法用了双线性/抗锯齿 | 全程最近邻，禁止半透明边 |
| 四个视图对不上 | 各视图独立绘制 | 共用画布高度、脚底基线、头高、色板 |
| 细节塞不下 | 在小画布上追求还原 | 按 S/A/B/C 分级砍细节，小画布只留 S |
| 比例怪（腿短得像侏儒） | 等比缩小 | 分段重映射，头部放大、靴筒加高 |

## 五、建议色板（按材质重建，16 色）

> 以下为本角色重建的起始色板，供后续调色使用。每材质三阶：亮 / 中 / 暗。

| 材质 | 亮 | 中 | 暗 | 说明 |
|---|---|---|---|---|
| 头发（银白） | `#F0F0F0` | `#C8C8C8` | `#9A9A9A` | 暗部略偏冷灰，与暖色衣物分离 |
| 皮肤 | `#F2C9A0` | `#DCA478` | `#B27A50` | 颈部/下巴投影用暗阶 |
| 衬衫（米白） | `#EFE6D4` | `#D6C7AE` | `#B3A188` | 挽袖后前臂为皮肤色 |
| 马甲（深褐） | `#7A5236` | `#5C3A24` | `#3D2517` | 全角色最重视觉块 |
| 皮带 / 皮具 | `#6B4526` | `#4E3018` | `#33200F` | 与马甲错开一点明度以分离 |
| 围裙（浅褐） | `#CDB99A` | `#AD9776` | `#8A7458` | 面积最大，破边用暗阶 |
| 金属（钥匙/扣） | `#D9C89A` | `#A89670` | `#6E5C3E` | 仅 2–4 px 点缀 |
| 裤（深灰） | `#46403A` | `#322D28` | `#211D19` | 弱化，不与马甲抢注意力 |
| 靴（棕） | `#7A4E2E` | `#5A351D` | `#3A2110` | 靴口翻边用亮阶 1 px |
| 描边 | — | `#2A1F1A` | — | 单色，全图统一 |

**配色检查：**眯眼把图缩到 25%，若马甲、围裙、靴三个块的明度差仍可分辨，色板即合格。

## 六、交付前质检清单

- [ ] 纯黑剪影可辨认（发 / 围裙 / 靴三特征成立）
- [ ] 单帧唯一色 ≤ 20，无半透明像素
- [ ] 所有边缘落在整数像素格，斜线阶梯均匀
- [ ] 描边为暖深褐，非纯黑
- [ ] 光源方向全图一致（左上）
- [ ] 四视图：头高、腰线、脚底基线三线对齐
- [ ] 四视图宽度符合"侧面 < 正面 < 背面"关系
- [ ] 导出 PNG + 最近邻，无 JPEG 中间环节
- [ ] 游戏引擎对齐：脚底居中，枢轴点（Pivot）在脚底中心

## 七、新角色复用流程（一页版）

```
1. 抠图 + 标四条参考线（头顶/下巴/胯/脚底）
2. 数源图头身比 → 查表定目标头身比 → 算各分段整数 y 坐标
3. 单色铺剪影，只求外轮廓成立
4. 列该角色的 S/A/B/C 特征清单（S 级不超过 4 项）
5. 按材质建 16 色卡（亮/中/暗）
6. 分块填中调 → 加一阶暗部 → 加金属/皮革高光
7. 上 S 级特征锚点，A 级最多留 3 处
8. 统一描边（暖深褐）+ 网格校验
9. 复制头部与三线骨架，横向扩出侧 / 背视图
10. 过质检清单 → PNG 最近邻导出
```
