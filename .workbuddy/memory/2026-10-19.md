## 光效 v1→v2：光圈硬边根因与连续光照场（用户指出"一眼看出是独立圆形"）
- 用户反馈：暖光下每个光池边界过锐，能分辨出独立圆图案。要求分析原因并做到"边缘自然融合、看不出单个光圈"
- **八条根因（v1 代码逐条对应）**：①衰减被量化 `int(t*levels)/levels` → 同心阶梯环 ②`if d2>=1: continue` 椭圆硬裁断 → 圆周轮廓线（主因）③加色 `r+color*amt` 且 255 截断 → 中心过曝平台+平台外硬边 ④多池分别相加 → 重叠处透镜状双圆边界 ⑤整池单色 → 像贴片 ⑥无视承光面明暗 → 光横跨墙/台/地 ⑦棋盘抖动只在外两档 → 外圈点阵环 ⑧无环境反弹 → 光斑孤立悬浮
- **v2 方案（`tools/relight_v2.py`）**：连续高斯 `exp(-k·d²)`（k=4.0，cut=2.0，不量化不裁断）→ 全部光先累加进统一 LightField 再一次合成 → 线性软加 `base + L·(255-base)/255` → 每灯拆 3 个抖动子瓣（`split_lobes` 打散正圆）→ 距离插值色温（核心→外围）→ 按底图亮度衰减 `att=1-0.55·Yb` → 大半径低强度环境光（7%/5%）
- **教训：光要有色，不能给近白核心**。第一版 v2 用 (255,246,224) 核心 + 环境 0.30 → 整屋糊成白雾；改成暖橙 (255,180,112)/(255,112,46)、环境压到 0.06~0.07 才成立
- 实测 Y：dusk v1 88.2→v2 91.3；night 55.4→59.8；dawn 80.6→84.4（更柔的扩散略微提亮，正常）
- 产物：`scene_{dawn,dusk,night}_v2_1x/2x.png` + `scene_dusk_v1_vs_v2.png`（整图+壁炉 3× 放大对照，v1 同心环 vs v2 连续过渡）
- 未采纳：Bayer 有序抖动量化的方案——当前基底是 AI 全彩图，抖动反而可能引入可见图案；若日后要回限色像素风再启用

## 光效 v3：伪法线定向 + 亮度层次归一（`tools/relight_v3.py`）
- 用户要求：保持边缘柔和的同时，加强亮度层次与光源方向统一，避免整体偏亮/偏暗
- **三处新增**：
  1. **伪法线定向着色**：对底图亮度做 Sobel 求梯度 → 法线 `(-gx·s, -gy·s, 1)` → 2 遍 3×3 平滑（压纹理噪点）；与主光 `Ldir=(-0.34,-0.86,0.38)`（上偏左）点积得 diffuse → `shade = 0.66 + 0.34·diffuse`
  2. **层次与方向**：光场乘 `dirw = 0.28 + 0.72·shade`（只落受光面）+ `grad = 1 - 0.32·u`（u 由左上到右下）；底图再乘 `1 - 0.10·u` 做整帧方向衰减
  3. **防失衡**：中灰对比拉伸 `c = 1.18`，再按目标平均亮度归一（dawn 81 / dusk 88 / night 56，允许 ±45%）
- **坑一：S 曲线写反了**。第一版 `t + 0.3·(t-t²)·(2t-1)·(-1)` 实际是"向中灰压缩"，反而拉平层次；改成线性中灰拉伸 `0.5+(t-0.5)·1.18`
- **坑二：法线把底图纹理放大成噪点**（桌沿出现零散亮点）。1 遍平滑不够，需 2 遍 3×3 + NORMAL_SCALE 从 1.05 降到 0.95
- 实测对比（黄昏）：sd 21.2→27.8、p10–p90 57→75；夜晚 sd 16.0→21.3、36→48；均值锁住 88.5/56.3/81.6
- 已验证：v3 壁炉 3× 放大无色带、无圆圈轮廓回归（色调曲线未把台阶打回来）
- 产物：`scene_{dawn,dusk,night}_v3_1x/2x.png`、`scene_v2_vs_v3.png`、`scene_dusk_v1_v2_v3.png`（三版对照+壁炉放大）

## 光效 v4：夜晚大范围/低对比/火堆为主体（`tools/relight_v4.py`）
- 用户反馈夜晚三问题：①对比度过高太突兀 ②焦点从火堆变成光圈中心光球 ③覆盖范围太小（暗房间该很大）
- **根因链**：小半径高强度核心（70/50 @0.82）+ 归一化放大到 1.45 倍 → 中心过曝成球、对比爆表、覆盖只在几圈
- **四项改动**：
  1. **能量摊大**：炉火三层半径 250/195、120/92、36/28（v3 是 70×50/26×19），核心强度反而降到 0.16；加两级环境（暖 580×430@0.11 + 冷 520×380@0.05）
  2. **软封顶**：`knee=0.6·max_light`，超过拐点后 `newmx = knee + over/(1+over/(max-knee))` 渐近逼近上限——**不用硬 clamp，否则大面积封顶会压出平台又变成圆盘**
  3. **降对比**：夜晚 tone_s 0.18→0.06，CLAMP_Y 0.45→0.18
  4. **火焰不参与归一**：`paint_fire()` 挪到最后一步，用**白天原图**的火焰掩膜（原图火最鲜艳、检测最可靠）+ 到火心距离做色阶（中心 #FCD284 / 边缘 #F29632），保证火焰永远是全图最高亮
- **坑三：方向梯度在夜晚会造斜锥**。BASE_GRAD 0.09/GRAD_STRENGTH 0.24 在夜晚让光晕变成朝右下的一道锥；改成 per-key 参数，夜晚降到 0.04/0.14（以炉火径向为主）

- 区域平衡实测：左 56.5 / 中 73.7 / 右 52.8，上 67.3 / 下 53.7（中心最亮、四周渐暗，无明显偏侧）

## 光效 v5：乘性曝光去雾 + 提亮（`tools/relight_v5.py`）
- 用户反馈：整体偏暗且"雾蒙/发灰发白"，要求提亮 + 修透视、保色彩层次
- **根因：v4 用加色合成** `base + L·(255-base)/255`，等于给全图铺一层恒定灰白光照 → 黑场被抬高、饱和度被冲淡 = 雾。加色对暗部是"加常数"，必然发灰
- **v5 四项**：
  1. **乘性曝光**：`out = base · (1 + L/255 · gain)`，每通道独立增益 → 0 仍是 0、天然带色温、不发灰
  2. **黑场恢复**：2% 分位 ×0.45 映射回 0（levels），去掉残留抬底雾（注意不能 1.0 全削，会把暗部压死：第一版 p05 变 0、sd 冲到 34+）
  3. **gamma 曝光**：夜 0.76 / 黄昏 0.78 / 黎明 0.80，提中间调不冲高光
  4. **对比 1.05~1.06 + 均值归一 + 饱和度补偿**（夜 1.15 / 黎明 1.10，抵消冷锚混色造成的灰）
- **坑四：乘性增益不能给太大**。首版 night gain 2.15 + 全削黑场 → 过曝、峰移到台面（@(290,130)），火堆不再是峰值。gain 降到 1.6 才把峰值锁回火心
- 实测 v5：dawn meanY 86.1 / sd 26.1 / p05 45；dusk 92.2 / 27.1 / 50；night 58.1 / 18.4 / 30；夜间峰值 @(315,65) Y=214 仍在火心
- 产物：`scene_{dawn,dusk,night}_v5_1x/2x.png`、`scene_v4_vs_v5.png`

## 桌椅分离（`tools/separate_furniture.py`）
- 目标：把场景里的桌椅拆成独立对象，位置/朝向/间隙合理、互不穿插、保持原风格
- **方法链**：白天图做分割（明暗差大）→ 颜色从夜晚 v6 取 → 暗轮廓 D(Y<60) → 地板种子洪水填充 → 轮廓内部按连通域分离（**描边天然是分隔线，所以长桌/长凳/椅各自独立**）→ 在 (内部∪描边) 上做**多源 BFS 分区**（每个内部吃最近的描边）→ bbox 内深色像素补入（椅子本体几乎全是深色，否则只剩碎片）→ 导出 RGBA
- 关键教训：①网格密集撒种子会顺着描边缺口漏进内部 → 必须稀疏种子；②描边膨胀 1px 会把内部吃掉；③等宽叠放的长桌+长凳没有行向窄颈，剖面切割无效，**只能靠内部连通域分**
- 产出 21 件：长桌×4(95×40) 长凳×7(78×20) 散座桌×2(43×36/46×49) 椅×7 木箱×1；附 `furniture_sheet.png`（2×/间距10px/标签）、`scene_night_v6_clean_bg.png`、`scene_night_v6_recomposed.png`（重组合成≈原图，证明抠图无损）
- 已知不足：椅子在图中本就是薄片状（靠背+座），提取偏碎；右下木箱/杂物未全识别，干净底图上有残留
