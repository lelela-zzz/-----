## 调色板评估 v1 → v1.1（多地形修订）

## 调色板评估 v1.1 → v1.2（多场景架构）
- 用户追问：场景会很多，是否继续往上扩色数，或按地形单独分色。
- 核心结论：**扩 48/64 是错的变量**。色数需求跟"单帧同屏材质数"走（8-12 材质 ×3 阶 ≈28-40），与地形总数无关；总色库可以 60-90，但单帧色数恒定。32 甜点 / 48 天花板 / 64+ 无意义。
- 采用架构：**核心 16（人与器物，跨地形不变）+ 地形 16（每地形实例化）**，单地形 ≤32。核心层刻意不含木/瓦/石/草。
- 关键区分写进文档：每地形共享 palette + 共享核心（可用） vs 每图各自 16 色（会崩）。判据：同地形内全共享，跨地形只共享核心。
- 最大收益：角色资产量不随地形数增长（否则 5 族×4 向会 ×地形数）。
- 工程建议：索引色 + palette LUT（Cocos 32×1 纹理 + fragment 查表），白拿昼夜/季节/受击换色。
- 文档更新到 v1.2（新增 §11，改 §0/§8），色板 JSON 仍未动，等确认架构后一次性落盘。

## 体积感修正（用户反馈：桌子没有脚、长凳太大）
- 根因：之前三件都画成"满格实心块"，俯视下读不出体积。体积感不能靠轮廓，要靠**腿**和**占格比例**。
- 改法：桌 → 桌面压到 y0-22，下方画两条 5px 宽前腿、腿间透空；凳 → 内缩 4px、只占下半 24px、加两条 5px 短粗腿。
- **沉淀经验：俯视下"有没有腿"是区分桌子/板/箱子的第一信号**，比木纹和描边都有效；腿间透空能透出地板色，白得"立在地上"的暗示。
- 复查：整格 6/6 通过，用色仍为 4/5/6 色（腿复用深木与描边，没新增颜色）。

## 可读性修正（用户反馈：长凳中间方块看不懂、酒桶像盾牌）
