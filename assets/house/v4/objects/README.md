## 编辑规则（会直接影响游戏表现）

1. **不要改画布尺寸**。`props.json` 里的 `sprite_rect` 是这件东西在 640×384 世界里的位置和大小，
   运行时按它摆放；尺寸一变，位置就对不上。真要改尺寸，改完告诉我，我同步 `sprite_rect`。
   （`sprite_rect` 和 `collision_rect` 是两回事：精灵范围按实际画面收紧，碰撞框还是手量的设计值。）
2. **只用 0 / 255 两种 alpha**。硬边，别用羽化/半透明过渡：
   拆件是叠在同一张背景之上的，半透明边会把下面的像素**二次混合**，出现暗边。
3. **保持硬边对齐原图的像素网格**（不要缩放、不要旋转）。
4. 透明区放什么都不会显示，可以放心擦干净。
5. **改完先备份**：`cp -r objects objects_edited`。重跑 `export_props_v15.py` 会覆盖全部 PNG。

### 吧台三件为什么这样切

吧台是 L 形，为了做 y 排序被拆成三段：**01 整条台面（含左端）**、**02 L 转角 + 竖板**、**03 左下端盖**。
三段的范围是**故意重叠**的——每件单独打开都完整，叠回原位像素完全一致（同一像素画两遍没有副作用）。
这样手改时不用对着三张图脑补接缝。

> 注意：03 的 `collision_rect`（70,194,82,26）比画面宽约 34px，那是当初为了"防钻"给的保守值。
> 等接 Godot 时可以按画面收窄，现在先不动。

## 排序点（`sort_y`）的含义

- 地面家具：`sort_y = rect 底边`，即这件家具踩在地板上的那条线。
- 贴墙件（`wall: true`，框顶 < 82）：`sort_y = rect 顶边`，让它**永远在角色后面**
  —— 壁炉、背柜、楼梯这些不可能被角色绕到后面。

运行时角色自己的排序点是**脚部**（角色节点原点就在脚下），所以：
角色脚在物体 `sort_y` 下方 → 角色盖住物体；脚在上方 → 物体盖住角色。
