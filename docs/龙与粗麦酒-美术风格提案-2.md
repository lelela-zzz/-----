## 0. 一句话

> 魔王死了几十年，刀剑挂上墙当了装饰。两个曾经互相厮杀的种族，如今在同一个吧台前，为最后一块面包讨价还价。

**类型**：中世纪魔幻 × 酒馆经营（模拟经营）。  
**基调**：**战后和平的日常**。底色是安全的、松弛的、带一点怅惘的——不是"随时会打起来的紧张"。

## 1. 故事背景（定稿，只此三条）

| # | 定稿内容                                        |
| - | ------------------------------------------- |
| 1 | 魔王被勇者击败，**至今约几十年**                          |
| 2 | 这几十年间，魔物与各个种族**逐渐交好**，达成**长期和平**，大规模战争已不复存在 |
| 3 | 舞台在**魔族领地与人类领地的交界边缘**——一条已无军事意义的旧国境线        |

**空白原则（重要）**：魔王叫什么、勇者是谁、当年怎么打的、种族完整名单、国境线怎么划的——**一律留白**。需要时再定，我不代填。这既是削减设定，也是保护：多写一条，就多一条后续要维护、并且可能和你的想法打架的设定。

唯一保留的舞台细节（可随时替换，非硬设定）：

- 国境线上还立着两根旧界石，斑驳但没被推倒——现在的作用是给行人指路。
- 当年的一座边关哨塔废弃了，塔下的空地成了**月度集市**。它不设防，只做买卖。

## 2. 主角设定

| 项     | 定稿                                               |
| ----- | ------------------------------------------------ |
| 身份    | **普通人**，在交界边缘经营一家小酒馆的店主                          |
| 位置    | 店面**几乎压在旧界线上**——一侧门朝人类领地，一侧门朝魔族领地                |
| 立场    | **主动远离纷争**，只想把日子过平静。不站队、不参与、不打听                  |
| 秘密    | **有，且不为人知**。具体内容**本阶段留白**（见 §4）                  |
| 秘密的位置 | **暗线伏笔**。是背景辐射，不是剧情引擎——它只改变"主角怎么看世界"，不改变"今天做什么菜" |
| 种族    | **人族**                                           |
| 性别    | **男**                                            |
| 年龄    | **中年**                                           |
| 外观    | **普通人类**：无特殊体征、不美型、不高不矮；靠服装与体态而不是长相建立记忆点         |

主角的核心魅力不在"他曾经是谁"，而在他**现在选择成为谁**：一个把两边客人都记住口味、会替吵架的人多添一杯的店主。这个人物不需要英雄履历也成立。

### 2.1 主角像素规格与配色

| 项  | 规格                                                                                                                                  |
| -- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 尺寸 | **24 × 48 px**（@1x，1.5 格高）／ @2x = 48 × 96                                                                                           |
| 姿态 | 直立站姿，正面（dir=0）。本轮只做正面，其余朝向后续批次                                                                                                      |
| 体型 | 中年体态：肩略宽、腰略厚、姿态微沉（不驼背，只是不挺拔）；剪影要"站得住"                                                                                               |
| 头发 | 短发，深褐掺灰；短须/胡渣（中年感靠这里，不靠皱纹）                                                                                                          |
| 服装 | 粗麻衬衫（袖口卷起）＋ 皮围裙 ＋ 布腰带 ＋ 粗布长裤；**无护甲、无武器、无披风**                                                                                        |
| 配色 | 肤色 `#A85A40` 中 / `#884030` 暗 ｜ 衬衫 `#A09888` 亮 / `#787868` 暗 ｜ 围裙 `#785028` 亮 / `#503818` 暗 ｜ 裤 `#585848` ｜ 发须 `#503818` / `#202018` |

**肤色方案（重要技术决定）**：16 色板里没有专门肤色，因此**复用现有色**——人族与矮人用赤瓦族（`#A85A40`/`#884030`，读作晒过的陶土色皮肤），精灵与兽人用石灰族（`#A09888`/`#787868`，偏冷偏白）。这样**不破 16 色上限**，且角色不会和木色家具粘在一起（这是"肤色=木色"方案最大的坑）。

> 代价：人族肤色偏暖偏土。若实际出图看着"太脏"，优先把 `#4A5A38` 深草（室内酒馆基本用不到）换成专用肤色，再决定是否接受 17 色。

### 2.2 世界种族构成（只定外观与客源，不写历史）

| 种族     | 身高        | 剪影特征                    | 在酒馆里的角色         | 色板锚           |
| ------ | --------- | ----------------------- | --------------- | ------------- |
| **人族** | 1.5 格     | 基准，无特征                  | 店主与本地常客         | 暖木 / 亚麻 / 陶土肤 |
| **精灵** | 1.6–1.7 格 | 瘦高、窄肩、尖耳、长袍             | 稀客，点得少但付得多，挑座位  | 石灰（浅）＋ 草木     |
| **矮人** | 1.1–1.2 格 | 矮宽、大胡须、方肩               | 酒量最大、声音最大，坐最久   | 暗瓦 ＋ 深木       |
| **兽人** | 1.7–1.8 格 | 魁梧、厚背、短毛                | 食量大、话少，靠门坐      | 石灰（深）＋ 暗瓦     |
| **魔族** | 1.5–1.8 格 | 异质感靠角 / 耳 / 尾，**不带攻击性** | 对侧常客，本作的"另一半客人" | 石灰 ＋ **霜青点缀** |

**硬约束**：

1. **种族辨识靠剪影，不靠配色**。16 色下颜色区分力有限，身高差与体宽差是唯一可靠的识别手段——先拉开剪影，再谈颜色。
2. 所有种族**共用同一 1px 描边、同一三阶明暗、同一光源**，只变更身高体宽与配饰。
3. **不写各族的来历、恩怨、政治**。他们是客源，不是阵营。需要时再定。

## 3. 叙事基调：三条铁律

| 铁律                    | 含义                        | 反例（禁止）             |
| --------------------- | ------------------------- | ------------------ |
| **没有战争，也没有"即将到来的战争"** | 危险只以天气、账本、食材短缺、口角误会的形式出现  | 魔王残党、边境摩擦、征兵、末日倒计时 |
| **和平是具体的，不靠旁白宣告**     | 和解体现在菜单、座位、称呼、价格、招牌的双面文字上 | 旁白念一段"如今各族和睦相处"    |
| **秘密不推动今天**           | 伏笔只加一层"你多看了一眼"的余味，不升级为危机  | 秘密暴露引发追杀 / 势力找上门   |

**情绪配比**：85% 温暖日常 ／ 12% 怅惘 ／ 3% 不安（一层薄薄的、说不清的违和感）。  
**幽默来源**：客人点单的误会、口味的文化差异、集市日的人挤人、账本赤字。不靠吐槽旁白。

**关于"小摩擦"**：两族客人偶尔会为座位、口味、旧称呼拌嘴——这是**市井喜剧尺度**，由主角调解，当天解决，**绝不跨章累积成冲突线**。这是本作唯一允许的"紧张"，且必须好笑。

---

## 4. 秘密：暗线伏笔规范（四条硬规则）

这是最容易失控的地方，所以写死规则，不写内容。

| 规则             | 要求                                  |
| -------------- | ----------------------------------- |
| **不命名、不解释**    | 前期不给答案，不给暗示性称呼，不写"他似乎想起了什么"式旁白      |
| **只呈现异常细节**    | 伏笔靠**可看见的物件与反应**，不靠心理描写             |
| **每章最多 1 条线索** | 且该线索必须**同时承担经营功能**（不能纯为伏笔存在）        |
| **伏笔不制造危机**    | 被发现的风险最高到"客人多看了他一眼"，绝不升级为追捕、战争、势力介入 |

**允许的伏笔载体**（都可直接落成美术资产）：

| 载体            | 说明                  | 经营功能            |
| ------------- | ------------------- | --------------- |
| 墙上的旧剑         | 当装饰挂着，锈了，被当成挂钩用     | 可交互装饰物，提升氛围值    |
| 不合身的旧斗篷       | 挂在后门，尺码和店主不符        | 可赠予客人的保暖物（冬季事件） |
| 柜底的一封信        | 从不出现在画面中心，只在一个镜头的边角 | 解锁条件，非任务道具      |
| 手上的旧疤         | 立绘/像素细节，不解释         | 无（纯视觉）          |
| 招牌背面的刮痕       | 旧字被刮掉，新字覆盖          | 招牌可升级/翻面        |
| 他对某种魔族食材的过分熟练 | 动作比语言快              | 解锁隐藏配方          |

> 设计原则：**玩家不追查也能玩得完整**；愿意看的玩家回头才发现这些一直都在。伏笔是给二周目的礼物，不是一周目的门槛。

## 5. 和平怎么被玩出来（经营循环）

没有战争，压力就必须来自**生计**而非**生存**。所有环节都是"过得好一点"，不是"活下来"。

| 环节      | 设计                                                                    |
| ------- | --------------------------------------------------------------------- |
| **招待**  | 客源 = 人类侧（农人、行商、旧兵）＋ 魔族侧（旅人、工匠、学者型魔物）。座位安排本身是玩法：谁愿意和谁坐一桌               |
| **口味**  | 两侧食材与口味不同（人类：麦、乳、根茎；魔族：菌、深岩酿、辛香料）。配方 = 跨文化调和的乐趣，不是战力数值                |
| **进货**  | 从两侧分别采购，汇率与季节波动；两条进货路线的平衡就是经营节奏                                       |
| **名声**  | 口碑决定来客构成与消费力。招牌挂两面、写两种文字——这是本作的"品牌"                                   |
| **集市日** | 旧哨塔下月度集市，单日人流高峰，需要提前备货（周期性的爽点）                                        |
| **扩建**  | 一间堂食 → 后院 → 二层客房 → 分店。进度感来自空间变大，不是打赢谁                                 |
| **四季**  | 淡旺季与节日。建议其一为「熔刃」（旧兵器熔了打成餐具与铃铛）——把"战争结束了"做成一个可以吃、可以听的节日。（**建议项，待你确认**） |

### 5.1 酒馆建筑与内部结构（本轮补充）

**命名**：酒馆**不命名**。招牌不写店名，只用图形符号（杯与碗），避免给后续留一个要维护的名字。

**骨架原则（最重要的一条）**：底图**只烘"搬不动的东西"**——地面铺装、墙体、吧台基座、楼梯、门洞、梁与天花线。所有会变的东西（桌椅、酒桶、货架、挂饰、地毯、灯具）全部做成**独立家具资产**，叠在 furniture 层。

> 这样"后续调整经营布局"永远不需要重画底图，换布局 = 换叠图。反过来，如果桌椅被烘进底图，第一次改布局就得重画整间店——这是最常见的返工来源。

**尺寸规格**（场景 20×12 格 = 640×384，tile 32）

| 部位     | 规格                         | 说明                         |
| ------ | -------------------------- | -------------------------- |
| 室内可用地面 | **18 × 8 格**（576 × 256 px） | 四周留墙，空间按"够摆 10–12 桌"设计     |
| 后墙     | 2 格高（64 px）                | 正交正立面，齐平画，**不画天顶、不画消失线**   |
| 吧台     | 6 × 1 格（192 × 32 px）       | 靠后墙左侧，**唯一固定件**，可交互        |
| 楼梯     | 2 × 2 格（64 × 64 px）        | 靠后墙右侧，通往二层（见下）             |
| 门洞     | 2 格宽（64 px）                | 开在下边界，正中偏左；一扇门朝人类侧，后门可朝魔族侧 |
| 主通道    | 2 格宽纵向净空                   | 门洞 → 吧台前，保证客人动线能走          |
| 剩余可摆位  | ≥ 150 格                    | 足够 10–12 桌（含座位）＋ 走道 + 后续增摆 |

**楼梯（正交约束下的画法）**：

- 占 2×2 格，靠后墙，踏步**横平竖直**：每级 8 px 高 × 12 px 深，轮廓为**阶梯状正交折线**。
- **严禁用 45° 斜线连接踏步端头**（那是最容易破坏正交语言的一处）；**不画斜扶手**，扶手改**垂直栏板**。
- 楼梯顶端上方留 2×1 格挑空，作为二层入口的触发热区。

**二层**：本轮**不建**，只留接口。要求是——后续加二层底图时**不需要改动一层底图**（楼梯位置与热区先固定下来，就是为了这个）。

**不做的额外设计**（按"内部不需要过多额外设计"执行）：底图里**没有**挂画、地毯、酒架、吊灯、装饰桶。这些一律是资产，不是底图。可选件只有一个：壁炉（2×1 格，靠后墙并与烟囱对齐）——**默认不加**，你确认要才画。

## 6. 视觉语言：交界地带的两种建筑语汇

和平不靠口号，靠**两套语汇在同一个画面里并存**。这是本作最重要的美术识别点。

|     | 人类侧                         | 魔族侧                                            |
| --- | --------------------------- | ---------------------------------------------- |
| 主材  | 木骨填石 + 红陶瓦                  | 深色石砌 + 暗瓦                                      |
| 主色族 | 暖木 `#785028` ＋ 赤瓦 `#884030` | 石灰 `#585848`/`#787868` ＋ 暗瓦 `#6A3024`          |
| 屋顶  | 出檐深、坡度缓、屋脊厚                 | 坡度陡、檐口薄、无翘角                                    |
| 窗   | 宽窗、木棂、暖光外溢                  | 窄高窗、石框、光更收敛                                    |
| 装饰  | 锻铁件、粗麻、陶罐                   | 霜青细线刻纹（唯一冷色来源）、石雕浅浮雕                           |
| 禁忌  | ——                          | **不用紫光、不用外发光**（16 色无紫，且违和）；靠"更暗、更窄、更陡 ＋ 霜青线"区分 |

**交界点（主角酒馆）= 混合体**，这是"和解"的视觉证据：

- 石基用人类的砌法（规整、灰泥勾缝）
- 梁与门窗用魔族的暗木与窄框
- 招牌**双面同一图形符号**（不具名，用「杯＋碗」标记），挂在门头正中、跨在界石连线上；两面各留一块**空白字牌**，后续可替换内容
- 室内同时存在两种座椅与两种杯型

**统一手段**（防止两侧风格散掉）：同一 1px 描边 `#181818`、同一三阶明暗、同一光源方向（上偏左）、同一色板。差异只在**材质配比与体量**，不在画法。

## 7. 风格锚点 v2.3（生成时整段逐字复制，只替换变量槽位）

> **v2.3 变更：视角从「正立面 straight-on」改为「高角度俯视」**。原锚点与实际认可的素材（床、桌椅）方向相反，已修正。详见 §16。

```
【风格锚点 v2.3 — 炉火镇】
画风：限色像素（当代独立游戏像素质感，非 8-bit 复古粗糙），哑光平涂，像素硬边
视角：正交高角度俯视（orthographic high-angle top-down），相机约 65–75°，
      轴对齐、无透视收敛、无消失点；顶面为主，垂直厚度只露一条窄立面；
      朝向仅 0/90/180/270
光照：单一暖光源，方向固定为「上偏左」；亮面在左上、暗面在右下；
      自发光只来自炉火与油灯
投影：硬边像素投影，统一朝**右下**，长度按物体高度（矮物 ≈2px，桌椅 ≈6–10px，
      建筑 ≈1 格）；投影为实心块 + 台阶边缘，禁模糊、禁半透明羽化
线宽：统一 1px 描边（@1x 下），外轮廓最深色 #181818，内部结构线用本族暗色
质感：哑光平涂 + 手工台阶明暗，每种材质 3 阶（亮 / 中 / 暗）；无噪点、无渐变、无反射高光
比例：建筑与家具按真实尺度呈现，不做 Q 版压缩；门高 ≈ 1.6 格，人高 ≈ 1.5 格
色彩倾向：暖棕—赤瓦—石灰为人类侧基调；深石—暗瓦—霜青为魔族侧基调；
          冷色（霜青）仅限魔族工艺 / 魔法痕迹 / 夜，全画面 ≤5%
氛围：战后和平的日常。干净、有人气、没有战损与废墟；
      桌上摆的是酒杯不是地图，墙上挂的是装饰不是兵器架
禁忌：禁等距 / 45° 斜置、禁 3D 透视与消失点、禁抗锯齿与渐变、禁软阴影、
      禁洋红及近洋红入画、禁紫光与外发光、禁哥特尖塔、禁日式 / 中式元素混入、
      禁金属镜面高光
```

**标准尾巴**（拼在每条 prompt 末尾）：

```
It MUST be an orthographic high-angle top-down view, camera roughly 65–75° above
the ground plane, axis-aligned, with NO perspective convergence and NO vanishing
point. Show mainly the top surface, plus a thin front face for vertical thickness.
Use a limited palette, pixel-perfect hard edges, hard-edged pixel shadows cast to
```

## 15. 网格对齐与元素分离规范（v2.2 新增）

> 这一节是**生产纪律**，不是美学偏好。违反它不会让图"难看"，但会让图**无法落格**。

### 15.1 三条铁律

| # | 铁律               | 含义                                              |
| - | ---------------- | ----------------------------------------------- |
| 1 | **一切地板元素必须独立出图** | 家具、树木、石头、木桶、摊位——一件一个文件，**不得与地板、墙面或背景合并**，不得自带投影 |
| 2 | **尺寸必须是整格**      | 画布宽高 = 格数 × 32px 的整数倍。**禁止 1.25 格、1.5 格这类尺寸**   |
| 3 | **内容不得越格**       | 横向严禁超出 footprint；底部必须贴底；元素之间的占格不重叠              |

### 15.2 四个必须分清的概念

| 概念                      | 定义                                                 | 谁在用       |
| ----------------------- | -------------------------------------------------- | --------- |
| **footprint（占格）**       | 整数格 `W×H`，决定摆放位置与碰撞                                | 玩法逻辑、摆放系统 |
| **sprite canvas（画布）**   | 实际 PNG 尺寸 = `W×32` 宽 × `(H + overhang)×32` 高       | 美术产出、图集   |
| **content bbox（内容包围盒）** | 不透明像素的实际范围，**必须 ⊆ 画布**，且底边贴画布底                     | 校验脚本      |
| **anchor（锚点）**          | `bottom-left`：内容底边贴 footprint 底边，左边贴 footprint 左边界 | 引擎        |

### 15.3 横向严禁 overhang，纵向允许但要登记

这是全节唯一需要拿主意的地方，说清楚取舍：

- **横向（左右）：严禁超格。** 超出去 1px 就会啃进相邻格，玩家并排摆两张桌子时会互相插进对方。屋檐的挑出量必须**算进 footprint**——footprint 是"看得见的宽度"，不是"墙体的宽度"。
- **纵向（向上）：允许 overhang，且必须登记。** 因为有个绕不开的物理事实：一棵树占 1×1 格，但视觉上要长到 3 格高；一栋房子的屋顶要高出占地范围。如果强行压进 1×1 = 32px，树就只有 32px 高，看起来像蘑菇。

| 元素    | footprint | overhang_up | 画布      |
| ----- | --------- | ----------- | ------- |
| 长餐桌   | 2×1       | 0           | 64×32   |
| 壁挂置物架 | 1×2       | 0           | 32×64   |
| 橡树    | 1×1       | 2           | 32×96   |
| 木石民居  | 12×7      | 4           | 384×352 |

**overhang 的代价**：它会让元素"向上压住"身后的东西，所以绘制顺序不能按 footprint 的中心，必须**按 footprint 的底边 y 排序**（底边靠下的后画）。这条定死了，遮挡关系才不会错。

### 15.4 如何清晰表达边界：四个层次

单靠 prompt 说不清楚边界，必须四层叠加。**越靠后越硬**：

**① Prompt 层**——显式声明占格与隔离要求，这是最容易漏的：

```
Single game asset: a wooden dining table.
Footprint: exactly 2×1 tiles (64×32 px at 32 px per tile).
The object must be fully contained inside that 64×32 px area — nothing cropped,
nothing protruding, nothing touching the canvas border.
View: orthographic high-angle top-down, camera ~70 degrees above the ground plane.
NO floor, NO ground plane, NO long cast shadow, NO background objects.
The object floats on a flat solid background. Transparent padding: 0.
```

> 关键在 **NO floor / NO long cast shadow / NO ground**。AI 默认会把家具"放在地上并打一条长投影"，那正是"与地板合并"，抠图后还会留一圈脏边。这三句必须写。
>
> **但"无投影"有个例外**：贴着物体底部那一圈 1–3px 的**接触阴影**（contact shadow）是要烘进去的——它和物体轮廓强绑定，引擎画不准。见 §15.6 与 §16.2 参考 B 的「贴地暗边」。

**② 文件命名层**——把 footprint 写进文件名，肉眼可见：

```
<类别>_<名称>_<W>x<H>_<朝向>@<倍率>.png
table_2x1_down@1x.png        64×32
oak_1x1_up_oh2@1x.png        32×96   (oh2 = overhang 2 格)
house_12x7oh4_down@1x.png    384×352
```

**③ 元数据层**——`*_info.json` 逐件登记，机器可读：

```json
{
  "file": "table_2x1_down@1x.png",
  "footprint": { "w": 2, "h": 1 },
  "overhang_up": 0,
  "canvas": { "w": 64, "h": 32 },
  "content_bbox": [0, 0, 64, 32],
  "anchor": "bottom-left",
  "layer": "furniture",
  "bg": "magenta"
}
```

**④ 工具校验层**——脚本卡住，不靠人眼。已落地 `tools/check_footprint.py`：

```bash
# 体检一个目录：尺寸是否整格、内容是否贴底
python tools/check_footprint.py inspect assets/house/v2/sprites --tile 32

# 按 manifest 严格校验声明值（不合规退出码 3，可挂 CI）
python tools/check_footprint.py check assets/sprites.manifest.example.json --tile 32
```

> 第 ④ 层是唯一能真正"控制住"的：前三层都是**声明**，只有第四层是**验证**。声明可以错，验证不会。

### 15.6 补充规则

| 规则                     | 说明                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| **阴影分两类处理**            | **接触阴影**（贴物体底部 1–3px 的暗边）**要烘进素材**——它与轮廓强绑定，引擎画不准；**长投影**（向外延伸的深色块）**不烘**，由引擎统一绘制，才能适配不同地面与昼夜 |
| **洋红底满铺，内容不邻边**        | 内容距离画布四边至少留 1px，否则抠图后边缘会残留洋红                                                                  |
| **窄于 footprint 时水平居中** | 左右余白必须为**偶数 px**，避免半像素错位                                                                      |
| **地面/墙体例外**            | 地面与墙体是**可平铺的基底**，本来就是"背景"，不受"独立元素"约束（见 §5.1 骨架原则）                                             |
| **@2x 单独体检**           | `inspect` 对 @2x 目录要加 `--scale 2`，否则格数会被算成两倍                                                   |

### 15.7 整改顺序（不动已确认设计）

1. **不重画**，先做**几何整改**：把现有的非整格尺寸向上取整（`table` 40→64 高即 2×1，或改为 2×1 并把多出的 8px 内容压回 32px）。
2. 逐件补 `*_info.json`，登记 footprint 与 overhang。
3. 跑 `check_footprint.py check` 至全绿，再进第二批产出。
4. 二批之后的资产**从出图阶段就按整格生成**，不再做事后整改。

> 一条经验：**整格是从 prompt 阶段定的，不是后期修的**。后期用裁切去凑整格，必然丢像素或加空白，越修越糟。

## 16. 透视基准 v1（v2.3 新增，依据用户指定的两张参考）

### 16.1 必须先说清的一个矛盾

你最初给的英文要求是 `orthographic front view (straight-on)`——**正立面，像看一面墙**。但这次你认定的正确参考（床、桌椅）都是**俯视**，从上方往下看。

这两个方向**互斥**：正立面看不见桌面，俯视看不见正面墙。不能同时成立。

以你的参考为准：**取俯视，作废旧的正立面要求**（§7 已改，旧尾巴已标废）。

影响面：

| 资产       | 影响                                                                       |
| -------- | ------------------------------------------------------------------------ |
| 家具、地面、地毯 | ✅ 立刻正确，本来就该俯视                                                            |
| 角色       | ✅ 70° 下头顶与肩可见，面部仍可读                                                      |
| **建筑外观** | ⚠️ **需要返工**。`house_down` 原为正立面（看得见墙面、门、窗），俯视下应改为**屋顶平面 + 一条前墙**。这是唯一的返工项 |

### 16.2 两张参考的逐条拆解

**参考 A · `bed_down@2x.png`（床）**

| 观察                     | 结论           |
| ---------------------- | ------------ |
| 床垫棋盘格完整平展、无透视收缩        | 接近 90° 的平面视图 |
| 床头板 / 床尾板只露出约 10px 的顶沿 | 垂直面几乎退化成一条线  |
| 四角床柱只见顶面小方块 + 一点侧边     | 高度被压缩到极低     |
| 无落地投影                  | 贴地物体不画投影     |
| 1px 深棕描边，木纹横向          | 描边与纹理的基本规范   |

**参考 B · 桌椅截图**

| 观察                     | 结论            |
| ---------------------- | ------------- |
| 桌面大面积平展，桌沿厚度可见约 12px   | 约 60–70° 高角度  |
| 杯子 / 面包 / 沙拉从上方看被压扁成椭圆 | 顶面主导          |
| 椅子看得见座面 + 前腿立面         | 垂直面窄，但存在      |
| 桌下、长凳下有偏**右下**的硬边深色投影  | 投影是体量与高度的主要线索 |
| 地板块纵向排列、从上方看           | 地面按俯视画        |
| 物体外沿另有一圈更深的「贴地暗边」      | 描边之外再加一层接触阴影  |

**看似矛盾，其实不矛盾**：床看起来更平，是因为它**矮**；桌子立面明显，是因为它**高**。同一台约 70° 的相机就能同时产出这两种观感。所以不需要为不同物件换角度——只需按物体高度决定露出多少立面。

| 物体类型         | 立面露出比例（占画布高）    |
| ------------ | --------------- |
| 贴地物（地毯、床、地面） | 0–10%           |
| 矮家具（凳、矮几）    | 10–20%          |
| 标准家具（桌、柜、桶）  | 20–30%          |
| 高家具（架、吧台、门）  | 30–40%          |
| 建筑           | 40–60%（屋顶平面占主体） |

### 16.3 相机规格（写死）

| 项    | 值                            |
| ---- | ---------------------------- |
| 相机俯角 | **65–75°**（目标 70°）           |
| 投影方式 | 正交，**无透视收敛**——平行线保持平行，不向消失点收 |
| 顶面占比 | ≥60% 画面面积                    |
| 垂直面  | 只露「厚度」，不露完整立面                |
| 投影方向 | 统一**右下**，硬边，长度随物件高度          |
| 旋转   | 仅 0/90/180/270，每朝向单独绘制       |

**为什么不上 90°**：俯到 90° 就看不见任何垂直面，**角色只剩头顶**，酒馆里的人就没脸了。  
**为什么不回 45°**：45° 是等距，已明确禁止。  
所以 65–75° 是「看得见人」与「看得见桌面」之间唯一的窗口。

### 16.4 与 §15 的联动：overhang 需求下降了

俯视下，树冠、屋檐本来就从上方被看到，**压在 footprint 内**，所以 §15.3 的纵向 overhang 会大幅减少：

| 元素        | 旧估（正立面）    | 新估（俯视）                   |
| --------- | ---------- | ------------------------ |
| 橡树 1×1    | overhang 2 | **0–1**                  |
| 木石民居 12×7 | overhang 4 | **0**（屋檐挑出量算进 footprint） |

→ 规则更干净了：**优先 0 overhang；能用 footprint 装下就不要用 overhang。**

### 16.5 参考图的使用边界（合规）

第二张是截图，**只提取结构特征**：视角角度、可见面比例、投影方向与硬度、描边策略。

**不复制其具体美术**——不复刻它的家具造型、配色、纹样。生成时不得写"照这张图的样子画"，只能写"按这个角度与投影方式画"。参考图是**沟通工具**，不是生成目标。

### 16.6 生成 prompt 模板（家具类，可直接套）
