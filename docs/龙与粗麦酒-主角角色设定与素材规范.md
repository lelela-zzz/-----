# 炉火镇 · 主角角色设定与素材规范

> 版本 **v2**｜2026-10-20（① 头身比 1:5.3 → **1:3 三头身**，头 16px ② 角色改**青年（约 20 岁）**、去胡茬 ③ **去掉围裙**，职业感由马甲+挽袖承担）
> 版本 v1｜2026-10-20｜依据：项目 canon（人族·男·中年·普通人、秘密留白）、色板 v4、技术基线（tile 32 / 70° 俯视 / @1x+@2x）、Godot 4.7.2
> 定位：**主角是一间旧酒馆的新老板**，不是冒险者。造型要让人一眼看出"店里的中年人"，而不是"要去打怪的勇者"。

---

## 0. 结论（先行）

| 项 | 定案 |
|---|---|
| 基础尺寸 | **24 × 48 px @1x**（宽 0.75 格、高 1.5 格；@2x = 48 × 96） |
| 头身比 | **1 : 3（三头身）**，头 **16px**（占总高 1/3）、身体 32px；头与肩同宽 |
| 主色 | 亚麻米白 + 深棕皮件 + 粗麻围裙，全部落在色板 v4 的暖棕系 |
| 职业识别件 | 无围裙；靠"**敞开马甲 + 挽到小臂的袖口**"建立（v2 起） |
| 绘制方向 | **3 向（前 / 侧 / 后）**，侧向左用镜像；设计保持左右对称以保证镜像不出错 |
| P0 帧量 | **18 帧**（idle 6 + walk 12），8 列排 → 192×144，填充到 256×256 |
| 禁忌 | 武器、纹章、魔法饰物、伤疤、戒指——一概不加（秘密留白） |

## 1. 角色定位（canon → 造型后果）

| canon | 对造型的直接约束 |
|---|---|
| 人族 · 男 · **青年**（v2 改） | 三头身、脸大；**去胡茬**，靠大眼与短发显年轻 |
| 普通人 | 无武器、无护甲、无徽记；只有围裙、袖套、钱袋三件"营生道具" |
| 刚接手旧店 | 衣服不新但干净：袖口磨白、围裙有一处补丁、靴子旧但擦过 |
| 秘密留白 | **不做任何特殊标记**（疤、纹身、异色瞳一律不画）；性格只靠体态暗示 |
| 交界两族 | 服装语汇以人族（亚麻 + 皮革）为底，**最多 1 处**魔族细节（围裙系带的铜扣），不扩散 |
| 长期和平的日常 | 不用高饱和红/金/紫；配色克制在暖棕与米白之间 |

## 2. 外观设定

### 2.1 比例（24×48 的像素分配）

| 部位 | 高度 | 说明 |
|---|---|---|
| 头顶—下巴 | 9 px | 头宽 10 px（方脸） |
| 颈 | 1 px | 几乎不露颈，显壮 |
| 躯干（肩—腰） | 13 px | 肩宽 14 px、腰宽 11 px |
| 腰—膝 | 13 px | 围裙在此段覆盖前侧 |
| 膝—脚底 | 12 px | 小腿 2 段，靴占 4 px |
| 合计 | **48 px** | |

宽度分配：肩 14 / 腰 11 / 臀 11 / 靴 7（单只 7，双脚并拢跨 14）。

### 2.2 头部与发型

- **脸型**：方脸，下颌略宽，颧骨不外扩。
- **发型**：短碎发，长度到耳中；**额前留 3px 不服帖的一撮**（这是唯一"性格"信号）；后脑略翘。
- **发色**：深棕近黑 `#3A2A22`，受光面 `#503818`。
- ~~胡茬~~：v2 改为青年，**不画胡茬**；面部保持干净（只剩眉、眼、鼻、嘴）。
- **五官**：眉骨重（2px 深线）、眼 2×1 px、鼻 1px 竖点；默认表情中性、嘴角略下。
- **耳**：1–2 px，侧面视图必须露出。

### 2.3 服装（从内到外）

| 层 | 件 | 形制 | 备注 |
|---|---|---|---|
| 内 | 亚麻衬衫 | 米白，**袖子挽到小臂中段** | 露出的前臂是"干活的人"的直观信号 |
| 中 | 深棕马甲 | 不系扣、前襟敞开 | 让衬衫形成一条竖向亮带，正面可读 |
| 下 | 长裤 | 深灰褐，直筒 | 与靴子交界处压 1px 暗边 |
| 足 | 旧皮靴 | 靴口翻边 | 靴底加 1px 暗线，避免"浮空" |
| 配 | 腰带 + 钱袋 | 皮革，钱袋在腰右侧 | 侧面视图要把钱袋画在朝向镜头的一侧 |

### 2.4 配色（全部取自色板 v4）

| 部位 | 主色 | 暗部 | 亮部 | 色板 slot |
|---|---|---|---|---|
| 肤色 | `#D9A066` | `#B57B47` | `#EDC08A` | 人族肤色三阶 |
| 头发 / 胡茬 | `#3A2A22` | `#202018` | `#503818` | dark-brown / aged-shadow |
| 衬衫 | `#C4BEB0` | `#8A8578` | `#D8D2C4` | plaster 系 |
| 马甲 / 靴 / 腰带 | `#5A3F26` | `#3A2A22` | `#8A6440` | leather 三阶 |
| 围裙 | `#BFA16C` | `#8A6440` | `#D6BC8E` | straw 系 |
| 长裤 | `#4A4238` | `#2E2A26` | `#6A5F52` | 石/褐过渡 |
| 描边 | `#181818` | — | — | outline |
| 魔族细节（可选 1 处） | `#7FA8A0` | — | — | frost |

**用色三规则**
1. 全身上下不超过 **8 个色号**（含描边），否则 24px 宽的 sprite 会花。
2. 亮部只用在"受光面"（头顶、左肩、围裙前片），**面积 ≤20%**。
3. 不新增色板外的色；确需新增，≤3 个并回写色板。

### 2.5 剪影规则（比配色更重要）

- **10% 缩略图测试**：缩到 2.4×4.8 px 时，仍能靠"围裙的外扩 + 短发的方头"认出是店主。
- **禁**：肩甲、披风、武器、长袍、夸张发型——这些都会让剪影读成"冒险者"。
- **允许的不对称**：只有钱袋（腰右）。若将来加挎包等不对称道具，必须**补画右向**，不能靠镜像。

## 3. 素材规格

### 3.1 尺寸与锚点

| 项 | 规格 |
|---|---|
| 单帧 | **24 × 48 px** @1x；**48 × 96 px** @2x |
| 锚点 | **bottom-left**（项目统一），即脚底左端对齐格子左下角 |
| 站立占格 | 1 格宽（24 < 32），高 1.5 格 → 跨 2 行，渲染时按脚底对齐 |
| 透明底 | 必须；出图用纯品红 `#FF00FF` 底，后处理 keyout |
| 像素对齐 | 所有帧位置取整，禁半像素（Godot `snap_2d` 开） |

### 3.2 方向

| 方向 | 绘制 | 说明 |
|---|---|---|
| 前（朝镜头） | 手绘 | 主视图，信息最全 |
| 侧（朝左） | 手绘 | 含耳、钱袋、围裙侧片 |
| 后（背对） | 手绘 | 围裙系带与后脑发型在此 |
| 侧（朝右） | **镜像左向** | 设计左右对称，镜像安全 |

> 若日后加不对称道具，右向需补画；这是本规格唯一预留的返工点。

### 3.3 帧表与动画状态

| 状态 | 方向数 | 帧/向 | 循环 | fps | 优先级 | 用途 |
|---|---|---|---|---|---|---|
| `idle` | 3 | 2（呼吸 1px 起伏） | 是 | 4 | **P0** | 站立、对话 |
| `walk` | 3 | 4（contact / down / passing / up） | 是 | 8 | **P0** | 移动 |
| `sit` | 3 | 1 | 否 | — | P1 | 坐凳、喝酒 |
| `work_bar` | 3 | 2（伸手—收回） | 是 | 6 | P1 | 吧台倒酒/擦杯 |
| `carry` | 3 | 4 | 是 | 8 | P1 | 搬箱、补货 |
| `talk` | 3 | 2 | 是 | 6 | P2 | 对话点头 |
| `sleep` | 1 | 1 | 否 | — | P2 | 打烊后 |

**帧量统计**
- P0：6 + 12 = **18 帧**
- P1 追加：3 + 6 + 12 = 21 帧（累计 39）
- P2 追加：6 + 1 = 7 帧（累计 46）

### 3.4 图集排布

| 阶段 | 帧数 | 排布 | sheet 尺寸 | 填充 |
|---|---|---|---|---|
| P0 | 18 | 8 列 × 3 行 | 192 × 144 | 256 × 256 |
| P0+P1 | 39 | 8 列 × 5 行 | 192 × 240 | 256 × 256 |
| 全量 | 46 | 8 列 × 6 行 | 192 × 288 | 256 × 512 |

@2x 同排布，尺寸 ×2（384 × 576 / 512 × 1024）。

**排列顺序固定**：行 = 状态（idle / walk / sit / work_bar / carry / talk），列 = 方向 × 帧（前1、前2…侧1…后1…）。行内不留空帧，行末补透明。

### 3.5 命名

```
hero_idle_front_00.png
hero_walk_side_02.png
hero_carry_back_03.png
hero_idle_front_00_2x.png
hero_p0_sheet.png / hero_p0_sheet_2x.png
hero_info.json
```

`hero_info.json` 必含：frame_size、origin(bottom-left)、states → {dirs, frames, fps, loop}、sheet 排布坐标。

### 3.6 导入设置（Godot 4.7.2）

| 项 | 值 |
|---|---|
| Filter | **Nearest**（关 mipmap） |
| Compression | **Lossless** |
| HDR / Glow | 关 |
| Sprite | `snap_2d` 开、`texture_filter` = Nearest |
| 图集 | 单张 sheet 手动切片，帧数固定，不做自动图集 |
| 描边 | 不靠 shader，直接画进像素 |

### 3.7 出图与后处理链

1. 纯品红 `#FF00FF` 底出图（或透明底直接出），128×192 或 256×384 起手（4–8 倍），避免 AI 在小尺寸上糊成一团。
2. **整数倍 NEAREST 降采样**到 24×48（禁非整数比）。
3. 去底：`keyout` 纯品红 → 透明。
4. 校验：色数 ≤ 8（含描边）、单帧内无半透明像素、脚底在最后一行。
5. 拼 sheet → 生成 `hero_info.json`。

## 4. 制作顺序

| 批次 | 内容 | 验收标准 |
|---|---|---|
| 1 | **前向 idle 1 帧**（定妆图） | 24×48 内认得出"中年店主"；色数 ≤8；10% 缩略图可辨 |
| 2 | 前向 walk 4 帧 | 步态左右交替正确，脚不滑（每帧脚底位移一致） |
| 3 | 侧向 idle + walk | 侧向钱袋与耳可见，朝向一致 |
| 4 | 后向 idle + walk | 围裙系带与后脑发型成立 |
| 5 | P1 状态 | sit / work_bar / carry |
| 6 | sheet + info.json | 行序正确、无错位、@2x 同步 |

**每批只做一件事**：先确认定妆帧，再铺动画——这是本项目反复验证过的收敛方式。
