## 一、技术合规（自动化检测，硬指标）

逐张跑 `透明边 margin / 孤立散点 / 软边占比 / 2x 一致性`，21 张全过：

| 指标 | 标准 | 实测 | 结论 |
|---|---|---|---|
| 透明边 margin（包围盒空白余量） | = 0，无浪费留白 | 全部 0 | 通过 |
| 孤立不透明像素（残缺 / 散点噪点） | = 0 | 全部 0 | 通过 |
| 软边（半透明）像素占比 | > 0，证明抗锯齿 | 6.2%–23.1% | 通过 |
| 放大模糊 | 2x 必须精确等于 1x 的 NEAREST 放大 | 21/21 精确相等 | 通过 |

> 说明：软边占比长桌偏低（6–8%）、长凳/椅子偏高（15–23%），符合几何直觉——长桌是宽大矩形边缘占比小，长凳/椅子细长边缘占比大。**旧版这些值为 0%（纯二值硬边），是锯齿根因**。

## 三、问题清单

无「需重做」项。以下为**已知限制**（非缺陷，标注避免误判）：

1. **椅子偏碎（源图属性）**——原始 AI 图中椅子是「靠背 + 座面」的薄片剪影，抠图忠实提取，故小尺寸下可读性弱于桌椅。若要改善，需在源图层重绘椅子或单独补画，超出抠图范围。
2. **右下木箱/杂物未全识别**——源图该区域家具与投影粘连，分割阈值未完全分离，干净底图（clean_bg）上仍有极轻残留。`cutout_compare.png` 末行可见，不影响已提取的 21 件。
3. **夜景色 vs 高清色**——精灵颜色取自夜景 v6（与旧版一致、风格统一）；高清母版存档 `obj_NN_hd.png` 为白天色，若日后引擎换光用到，需重新跑换光管线，不能直接套用。
