### 0.1 B2 的设定修正，影响不小

原设定是"这店开了几十年，家具用旧了"。改成**"主角刚接手一间旧店"**后，气质完全不同，而且**更好**：

| 变化 | 美术后果 |
|---|---|
| 旧 = **别人用旧的** | 家具**风格不统一**：桌子有方有圆、椅子不成套、木色深浅不一。这是"混为一体"（B3）天然的视觉理由 |
| 刚接手 | 店里**东西少、还没摆满**，有一处**待整理区**（未拆的箱子、倒扣的凳子、卷起的地毯） |
| 正在经营 | 吧台与壁炉已恢复使用（有火、有酒），其余地方还在慢慢收拾 |

> 这个改动顺手解决了三件事：解释了为什么空置率这么高、解释了为什么家具不成套、给了玩家"从二手旧家具经营到定制家具"的成长动机。**不需要额外增加任何设定，只是把"旧"的来源换了。**

### 2.2 为什么这么排（三句话）

1. **十字通道**把 18×8 切成四个象限，客人进门笔直走到吧台，中间不穿过任何桌子——这是所有经营类布局里返工率最低的一种。
2. **服务在上、客座在下**，因为后墙必须贴服务设施（吧台/壁炉/背柜），而客座需要靠近门。上下关系一旦对了，以后加桌子只会往两侧长，不会动骨架。
3. **左右客座不同型**（长桌 vs 散座），让同一张画面里同时出现"结伴喝酒"和"独自坐着"两种信息——这是最省力地表达"这店有人气"的办法。

### 2.3 动线

```
   ┌── 后墙：小门 · 窗 · 壁炉 · 背柜 · 窗 · 楼梯 ──┐
 ↙ 后院/库房（走廊左端）
   │  ╔═════ 吧台后走廊 row 2–3（主角活动区）═════╗ │
   │  ╚══════════════════════════════════════════╝ │
   │  ▓▓▓▓▓▓▓▓▓▓ 吧台 10×1（row 4）▓▓▓▓▓▓▓  [酒桶] │
客人→│ ════════ 横向主通道 / 沿台点单（row 5–6）════ │
   │   左客座（长桌·旧）  竖通道  右客座（散座·混搭） │
   └──────────────── 主门（2 格）──────────────────┘
```

**两条线彻底分开**，这是把吧台前移最大的收益：

| 线 | 路径 | 特点 |
|---|---|---|
| **客流** | 主门 → 竖向通道（cols 9–10）→ 横向通道 → 沿吧台点单 ≈ **8 格** | 不穿过任何座位，也不进后走廊 |
| **后勤** | 后走廊（cols 1–15）→ 左端小门 → 后院/库房 | **完全在吧台之后**，与客人零交叉 |

原方案的"吧台贴墙"会让后勤线与吧台挤在同一格，主角取货要绕。前移后，主角在走廊里横向走动，客人永远碰不到他——**这就是真实酒吧的布局逻辑**。

### 2.4 三版底图怎么分工（B1）

三版 = **白天 / 黄昏 / 夜晚**，先出黄昏。但三版**不是三张不同色调的图**，那样会和昼夜 LUT 打架。

| 层 | 由谁负责 | 三版之间变什么 |
|---|---|---|
| 基础材质（木地板、石墙、家具） | 底图 | **不变**。保持同一天白度，暗化交给 LUT |
| **光斑与阴影的"形"** | 底图 | **这才是三版的差别** |
| 整体色调（明度/冷暖） | 运行时 LUT（色板 v4 四帧） | 连续变化 |

三版底图的具体差别：

| | 白天 | 黄昏（先做） | 夜晚 |
|---|---|---|---|
| 窗光 | 两片斜向冷白光斑落在地板上 | 光斑变暖、拉长、强度减半 | 窗外几乎无光，光斑收缩成窄条 |
| 炉火/灯 | 弱，仅炉口微亮 | **主导**：地面暖橙光池 + 桌面亮块 | 唯一光源，光池收缩、对比最强 |
| 暗部 | 少，角落浅 | 中，墙角与桌下有暗 | 多，非光区整体压暗 |

> **一条硬规则**：三版底图的**暗部不要预先画黑**。如果底图已经按夜晚压暗，LUT 再压一次就是双重压暗，会糊成一片。底图只负责"光在哪里、什么形状"，不负责"有多黑"。

### 2.5 B2 的落地：哪些家具该"不成套"

设定了"旧家具是上一任留下的"，就要在画面上看得出来，否则等于没设定。

| 该有的迹象 | 具体做法 |
|---|---|
| 桌型不统一 | 左区一张圆角长桌 + 一张方角长桌；右区两张方桌 + 一张圆桌，木色深浅差 1 阶 |
| 椅子不成套 | 有靠背椅、有板凳、有倒扣在桌上的 |
| 修补痕迹 | 一条桌腿缠麻绳、椅面钉过补丁、桌面有烫环 |
| 待整理 | 4×1 格待整理区：2 个木箱、1 张卷起的地毯、2 张倒扣的凳子 |
| 用得最勤的地方最旧 | 吧台前沿磨得发亮、门槛踏薄——这两处是"店真的在用"的证据 |

### 2.6 小门的宽度

小门定 2 格宽（64px），与主门同宽。理由：**后勤门要能过酒桶**。它现在位于后走廊左端，主角从吧台后向左走即到，补货路径最短。

### 2.7 本轮调整（v2 → v3）的四个连带后果

吧台前移不是一个孤立改动，它连带改了三处，每一处都要说明为什么：

| # | 连带改动 | 原因 |
|---|---|---|
| 1 | **壁炉从"地面 2×1"改为"墙面 2×2"** | 走廊 row 2–3 必须保持通畅。壁炉若还占地面 2 格，主角走到那儿就得绕。改为嵌进后墙（wall_decor 层），炉口与火光仍照在走廊与吧台前——**视觉不变，通行变好** |
| 2 | **竖向通道从 row 6 起改为 row 7 起** | 吧台占了 row 4 的 cols 1–10，通道若还从 row 6 起会正好撞台面。下移一行后，客人在 row 5–6 横向通道里沿台走，不穿台 |
| 3 | **客座区从 5 行压到 4 行** | 走廊 2 行 + 吧台 1 行 = 吃掉 3 行，只能从客座里出。**这不完全是损失**：B2 设定是"主角刚接手的旧店"，桌少、空着才对；4 行 × 18 列仍可摆 8–10 桌，足够 |
| 4 | **小门从后墙右端移到左端** | 按你的要求放到"吧台后走廊的左侧"。左端正好是走廊起点，主角从吧台往左走三步就到，比放右端（要先绕过楼梯）合理 |

**没有改的**：后墙 2 格、主门位置（cols 9–10 下边界）、楼梯（cols 16–17）、客座左右分型、空置率（≈50%，仍 ≥40%）、木地板纵铺。
